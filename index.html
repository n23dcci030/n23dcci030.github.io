Biography

Tôi là sinh viên ngành IoT, quan tâm đến Arduino, hệ thống nhúng và xử lý dữ liệu cảm biến. Tôi đang phát triển các dự án hiển thị dữ liệu nhiệt độ và ứng dụng GitHub trong quản lý mã nguồn.

Trang web này được xây dựng bằng HTML/CSS và triển khai bằng GitHub Pages.
